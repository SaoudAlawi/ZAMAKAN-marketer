# ZAMAKAN reference library

62 campaigns (62 checked live), collected by the reference scout across client jobs. One page per campaign in `campaigns/<name>/REFERENCE.md` (facts, links, idea, insight, execution, results); `references.jsonl` is the same data for agents.
Client-specific judgement (why a campaign mattered for a client, what to borrow) is kept in that client's private folder.

Search from the command line: `python3 .claude/skills/zamakan-reference-scout/scripts/library.py search ramadan --country SA`
