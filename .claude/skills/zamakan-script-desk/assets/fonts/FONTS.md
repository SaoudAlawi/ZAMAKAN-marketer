# Bundled fonts (SIL Open Font License 1.1, https://openfontlicense.org)

| File | Family | Use | Source |
|---|---|---|---|
| CourierPrime-Regular/Bold.ttf | Courier Prime (Quote-Unquote Apps) | Latin screenplay text (a free Courier made for screenplays) | Google Fonts |
| NotoNaskhArabic-Regular/Bold.ttf | Noto Naskh Arabic (Google) | Arabic text in PDFs and previews | Google Fonts |

The Word files name the fonts; Word uses them if installed, else substitutes. PDFs made by `format_script.py` embed them.
