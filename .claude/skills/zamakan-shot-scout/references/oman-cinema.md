# Omani cinema: where to find it, and a checked starting list (2026-10-18)

ZAMAKAN is an Omani agency, so Omani films come first in any regional part of a programme or board. Omani cinema is
young and mostly **short films and documentaries**; few are on Wikidata or streaming platforms, so finding them takes
these sources rather than `film_facts.py` alone.

## Where Omani film lives
| Source | Use | Notes |
|---|---|---|
| **Oman Daily** (omandaily.om, Arabic) | festival news, awards, film synopses | Readable with `discover_shots.py page <url>`; search in Arabic: «فيلم عماني», «مخرج عماني», «الجمعية العمانية للسينما». |
| **Oman Observer**, **Times of Oman**, **Oman News Agency** (English) | festival results, interviews | |
| **Gulf Film Festival** (Muscat hosted the 2025 edition) | GCC features, shorts, documentaries | Results via Oman Observer. |
| **Dhofar International Film Festival** (Salalah, first edition 2024; Oman Film Society) | Omani shorts | Results via Oman Daily. |
| **Saudi Film Festival** (Ithra, Dhahran) | Omani entries each year | Lineups via Oman Daily. |
| **Atlas International Film Festival** (Morocco) | Omani prize winners | |
| **Oman Film Society** (الجمعية العمانية للسينما) | the community, festivals | Chaired by Mohammed bin Abdullah Al Ajmi (per Oman Daily, 2024). |
| Wikidata / Wikipedia | the few Omani features listed | Thin: Wikidata lists only a couple of Omani films. |
| YouTube / Vimeo | trailers and some full shorts | Search the Arabic title + the director's name; check the uploader is the filmmaker. |
| Book: *Transformations of Omani Cinema 1970–2020* (Mohammed Al Kindi) | history and context | Launched at the Gulf Film Festival 2025 (Oman Observer). |

## How to use it
- In Inspire me, open the regional part with an Omani title that fits the theme; say honestly when it can't be
  streamed ("festival film: watch for screenings, or ask the Oman Film Society"), and put that in `watch_list`.
- In client work (subject or frame-match), search Omani makers first for local looks: YouTube in Arabic, Oman Daily.
- Add new finds here with their source, so the list grows with every run.
