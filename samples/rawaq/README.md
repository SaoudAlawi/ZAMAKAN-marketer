# Sample client: Rawaq Coffee Roasters (رواق)

A **fictional** Riyadh specialty-coffee brand, used as the fixed test input for all
ZAMAKAN skill development. `input/` is exactly what a client would hand the agency:

| File | What it is |
|------|------------|
| `input/Rawaq_Brand_Guidelines_v2.1.pdf` | 19-page bilingual brand guideline (A4 landscape) |
| `input/Logos/` | Outlined SVG masters + PNG exports (stacked, horizontal, symbol, reversed, mono) |
| `input/Fonts/` | The four brand typefaces (all SIL Open Font License — see `OFL.txt`) |

## Deliberate real-world difficulties
The guideline is built to be as messy as real client PDFs:
- Arabic text extracted from the PDF is garbled (broken letters, wrong ligature order).
- The logo-misuse page is a flattened image — no extractable text.
- One colour's HEX appears on a different page than its swatch.
- One colour's HEX is stated inconsistently on two pages.
- Embedded PDF font names don't reveal the real weights.
- Several things a design system needs (spacing, UI radii, buttons, shadows) are not specified.

The full ground truth lives in `evals/fixtures/rawaq/answer-key.json` and must **never** be shown
to the agent under test.
